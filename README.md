# 115 Userscripts

给 **115 网盘**用的三个油猴脚本，配合本机的刮削服务（可选），把网盘里的影片变成
「Emby 式」的媒体库：**文件名规整 → 同目录落海报/NFO → 海报墙浏览 → 播放器补强**。

> 产物是**网盘目录里的实体文件**（`<视频名>-poster.jpg` / `<视频名>.nfo`），
> 不依赖任何后端鉴权 —— 换播放器、换设备、用 Emby / VidHub / Infuse 都直接能读。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（Chromium 内核 / Firefox 均可）
2. 打开 Tampermonkey 管理面板 → 把 `.user.js` 文件**拖进去**（或点「实用工具 → 导入」）
3. 打开 `https://115.com/` 即可看到入口

⚠️ **升级时注意**：`115整理助手` 早期叫 `115AV整理助手`，如果你装过旧版，
**先在 Tampermonkey 里删掉旧条目再装**，否则会出现两份。

## 1. `115整理助手`

递归整理 + 批量改名。

### 整理流程

```
递归扫描当前目录及子目录
  → 去掉文件名里的干扰词（广告、水印、编码标记…）
  → 抽取番号
  → 视频汇总到当前目录（清空子目录）
  → 按「重命名方式」改名
  → 删除已清空的子目录
```

### 命名方式

内置 7 种，默认 `番号-标题-演员-日期`（**刻意保持通用**，避免"只点一次改名就发现风格全变了"）：

| 方式 | 结果示例 |
|---|---|
| 番号-标题-演员-日期 | `ABF-208 禁欲の果てに… 涼森れむ 2025-03-13.mp4` |
| 番号-标题 | `ABF-208 禁欲の果てに….mp4` |
| 仅番号 | `ABF-208.mp4` |
| …（另 4 种） | |
| **自定义模板** | 自己编，见下 |

**自定义模板**在整理预览面板里就地展开，不用进设置：

| 变量 | 含义 |
|---|---|
| `{code}` | 番号 |
| `{title}` | 标题 |
| `{actress}` | 演员 |
| `{date}` | 发行日期 |
| `{rating}` | 评分 |
| `{markers}` | 语义标记（如 `【中文字幕】`） |

- 边打字边重算下面表格里的新文件名（防抖 220ms，**纯本地、零请求**）
- 旁边 6 个变量按钮，点一下插到光标处
- 示例用的是**你面板里的真实条目**，不是假数据

### 本地优先

先用文件名算出全部新名，**只有缺片名的条目才联网**（并发 3）。切换命名方式只是重算，不发请求。

### 干扰词自学习

词典 = 内置种子 + 本地学到的。规则：
- 方括号标签见到就学
- 其余词需要 ≥2 个文件同时出现才学
- **语义标记不算干扰词**（中字/无码/破解/流出/4K/8K/VR 会保留成 `【中文字幕】`）
- 不会拆坏番号；只有真的删掉了词才收敛多余的分隔符

### 撤销上次改名（回滚）

改名（含整理里的批量改名）开始时会记下这一批的 `fid → 原名 → 新名`，存进油猴存储。

- 菜单里点「撤销上次改名(回滚)」→ 弹出「新名 → 原名」清单 → 确认后逐个改回去
- 回滚**本身可以再撤销一次**（成功后自动写入反向映射），点错不怕
- ⚠️ 只改文件名，**不会把文件移回原来的子目录**；若某个文件在那之后又被改名过，回滚会覆盖那次改动
- 只记「最近一批」（上限 800 条），所以叫「撤销**上次**改名」而不是「改名历史」

## 2. `115影片墙`

把 115 里的影片渲染成海报墙（Emby 式）。

### 数据从哪来

**优先读视频同目录的 sidecar** —— 一次列目录就够，零抓取、零鉴权：

```
<视频名>-poster.jpg   竖版海报（约 1032×1468）
<视频名>-thumb.jpg    横版封面（常见 2184×1468，最清晰的一张）
<视频名>-fanart.jpg   横版剧照（约 800×538）
<视频名>.nfo          Emby 标准元数据（标题/演员/剧情/标签/厂牌/系列/导演…）
```

这些文件由本机的刮削服务「导出媒体文件」写入网盘，**也可以完全不用刮削服务**——
手动放好同名的图和 nfo，影片墙照样能读出来。

读不到 sidecar 时，会退到刮削服务接口 / DMM / JavDB 等图源。

### 主要功能

- **两个范围**：当前文件夹 / 全库递归
- **两种视图**：海报墙 / 紧凑列表（一行一部，左侧小缩略图 + 右侧番号·标题·目录；扫番号更快）
- **详情面板**：剧情简介、标签、原名、厂牌、发行、系列、导演、时长、分级、国家、评分、数据来源 + 文件信息，卡片一行放不下的都在这里
- **排序 8 种**：番号 / 文件名 / 目录 / 演员 / 类型 / 评分 / 观看日期 / 随机
- **批量移动 / 删除**：勾选卡片 → 预演 → 执行，**会自动连带同目录的海报与 NFO**（不留孤儿产物）
  - 操作完**卡片原地摘除，不刷新页面** —— 已加载的图不重下、滚动位置不动
  - 同番号的多个版本（正片 / 带字幕版 / 4K 版）**各自独立**，不会"删一个把同名的都删了"
- **本地缓存**：NFO 原文 + 解析结果 + 海报原图自动存到本地（IndexedDB，或你自选的本机文件夹），重开**零请求秒出**
- **素材实时存本地**：缓存位置可选「浏览器本地」或「你自选的本机文件夹」（写成磁盘真实文件，可备份可复用）

### 卡片用哪张图

| 设置 | 用哪张 |
|---|---|
| 竖图模式 = 开 | `-poster.jpg`（竖版海报），卡片比例 2:3 |
| 横版卡片用哪张图 = **横版高清**（默认） | `-thumb.jpg` / `-fanart.jpg` 里**体积最大**的（实测中位 776KB，最清晰） |
| = 横版剧照 | `-fanart.jpg` |
| = 竖版海报 | `-poster.jpg`（放进横版卡片会整张完整显示 + 两侧模糊铺底，不裁切） |

**低清守卫**（默认开）：抓到的海报有时只有 147×200（上游拿不到高清源时的兜底小图），
挑图会**跳过低于 24KB 的候选**改用同名的清晰图；实在只有小图时不拦。

### 点卡片

用 115Master 播放器打开 `https://115.com/web/lixian/master/video/?pick_code=<pc>`。
装了下面的补丁版 115Master 就是增强播放器，没装也能走 115 官方播放页。

## 3. `115Master` 补丁版

> ⚠️ **这是第三方脚本的补丁版**，原脚本 [115Master](https://github.com/cbingb666/115master)（作者 **cbingb666**，1.13.0）。
> 本仓库提供的是**打好补丁的完整脚本**，原作者署名与许可保持不变。

### 补丁① 字幕下载到视频目录

播放器里点「下载」字幕时，**直接上传到视频所在目录**（同目录同名），而不是下载到你本机：

- **直传优先** → 原生上传入口兜底（原生入口只能确认"已交给 115"，看不到最终结果）
- 失败会**写明原因**，并回退成本地下载（不会丢文件）
- 字幕统一转成 115 能接受的扩展名（`.vtt` → `.srt`）

好处：CloudDrive2 之类挂载后，IINA / PotPlayer / Infuse 都能直接读到同目录的字幕。

### 补丁② 字幕延迟调节

115 播放器内核**本来就有**字幕延迟 API，但官方 UI 和原脚本都没把它暴露出来。本补丁接了出来：

| 操作 | 默认键 |
|---|---|
| 字幕**延后** 0.5 秒 | `x` |
| 字幕**提前** 0.5 秒 | `z` |
| 延迟**归零** | 未绑（可自己绑） |

- 按下后屏幕上方显示当前偏移量，全屏下同样可见
- 改键：**设置 → 快捷键 → 字幕**
- ⚠️ **如果你以前保存过快捷键配置**，默认键位不会自动生效（你的配置优先）→ 去上面那个位置绑一下
- ⚠️ **只有 `.mkv` / `.avi` 走的内核支持**（`.mp4` 等走浏览器原生内核，内核里就没这个能力）

### 安装前必读

- **不要让它自动更新** —— 补丁版已删除 `@downloadURL` / `@updateURL`，
  否则 Tampermonkey 会自动更新回官方原版，补丁全部丢失
- 安装时若提示与官方版冲突，先禁用/删除官方条目

## 开发

```
node tools/check.js             # 静态体检：语法 / @grant / @connect / 版本号有没有记进 CHANGELOG
node tools/build.js             # 把 src/core/115-core.js 内联进 scripts/*.user.js
node tools/build.js --check     # 只对比不同步、不改文件（提交前用）
node --test tests/core.test.js  # 公共核心的单测 + 接线回归
```

- `scripts/*.user.js` 是**构建产物** —— 为了保持「拖进 Tampermonkey 就能用」的单文件形态。
  改完 `src/core/115-core.js` 之后**必须**跑一次 `node tools/build.js`，产物也要跟着提交。
- 公共核心里只放**纯函数**：不吃 `GM_*`、不碰 DOM、不联网。
  这三个脚本跑在别人的浏览器里，没有 115 测试账号、也模拟不了 `GM_*`，
  所以能被自动化验证的只有这一层 —— 这也是把公共逻辑抽出来的主要动机。
- 改动记录见 [CHANGELOG.md](CHANGELOG.md)。

## 说明

- 这些脚本只在你自己的浏览器里运行，不上传任何数据到第三方服务器
  （只有"联网补片名/评分"这类功能会去公开信息站点查询）
- `115影片墙` 的「本机刮削服务」是**可选的**：它负责把刮削结果写成网盘里的海报/NFO，
  没有它，影片墙就只显示文件名与已有的 sidecar
- 请遵守所在地区的法律法规，仅用于整理你合法拥有的内容
